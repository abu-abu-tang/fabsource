# 简历项目描述

## 版本 A：供应链 / 采购岗

**FabSource 半导体设备寻源比选工作台｜独立设计与开发**

- 面向 12 英寸晶圆厂 CVD 干式真空泵采购，设计包含技术硬门槛、报价归一、五年 TCO、交付服务和供应风险的可解释决策模型，比较 4 家供应商及 16 项技术与商务指标。
- 使用 Next.js、TypeScript、ExcelJS 和 Recharts 完成 Web 工作台，支持 XLSX/CSV 导入、四套权重策略、实时敏感性分析、计算轨迹与 XLSX 决策包导出。
- 将币种、税率、Incoterm、能耗、维护、停机损失和残值纳入 TCO；通过硬门槛排除缺少 SEMI S2 的低价方案，展示“最低采购价不等于最低总成本”的采购判断。

## 版本 B：供应链数据分析 / 数字化岗

**FabSource 半导体供应链决策产品｜独立开发**

- 从 0 到 1 将设备采购问题拆解为需求、报价、TCO、评分、推荐五段流程，建立供应商、报价、技术要求、数据来源和审计事件等 10+ 类数据模型。
- 使用 Zod 完成报价字段校验和异常行提示，使用 Zustand + localStorage 实现无后端状态管理，使用 Vitest 与 Playwright 覆盖计算、策略切换、导入和导出场景。
- 设计 OPTIONAL BYOK AI 架构：模型仅生成分析文字，不能修改评分和排名；无 Key 时自动降级为规则摘要，保障公开 Demo 的可用性和可解释性。

## 面试口头版（30 秒）

“我做了 FabSource，一个晶圆厂干式真空泵寻源比选工作台。它不是普通看板，而是把技术门槛、五年 TCO、停机损失和供应风险放在同一套可复算模型里。演示时切换‘成本优先’和‘停机优先’，首选会从荏原变为爱德华兹，同时缺少 SEMI S2 的低价供应商会被硬门槛淘汰。这个项目主要证明我能把供应链问题产品化，并保留采购决策需要的证据和审计链路。”

## 使用边界

简历中不要写“帮助企业降本 X%”或“被企业采用”，除非后续获得真实试点和可核验数据。当前项目最稳妥的表述是“独立设计”“教学模拟数据”“可复算 Demo”。
