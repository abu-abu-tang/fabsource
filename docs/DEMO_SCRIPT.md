# 5 分钟演示脚本

## 0:00-0:35 问题与角色

“目标岗位是晶圆厂设备/备件采购。晶圆厂买干式真空泵时，最低采购价可能意味着更高能耗、更长停机或缺少 SEMI S2 证据。我做 FabSource，把技术门槛和五年 TCO 放到同一套可审计模型里。”

依次指出：CVD Sub-fab 场景、6 台设备、4 家供应商、教学模拟报价声明。

## 0:35-1:20 技术与合规门槛

进入“规格门槛”：

- 说明抽速、极限压力、功率、腐蚀气体兼容、MTBF 和 SEMI S2。
- 指出 Busch 缺少 SEMI S2，即使采购价格更低也会被淘汰。
- 强调硬门槛不是权重，不能用折扣弥补。

## 1:20-2:05 报价归一

进入“报价归一”：

- 展示美元、欧元和人民币报价。
- 解释汇率、税率、Incoterm、运输关税、安装和服务合同必须先统一口径。
- 打开导入模板或导入 CSV，说明支持 XLSX/CSV 与逐行错误校验。

## 2:05-3:10 TCO 与权重

进入“决策分析”：

- 指出五年 TCO 包含采购、能耗、维护备件、服务和停机损失。
- 点击“成本优先”，首选为 Ebara。
- 点击“停机优先”，首选切换为 Edwards。
- “排名变化不是算法不稳定，而是业务偏好在成本与停机风险之间发生改变。”

## 3:10-4:00 推荐与谈判

进入“推荐与谈判”：

- 说明首选、备选、淘汰原因和风险追问。
- 强调输出不只“选谁”，还包括目标价、质保、响应时间和备件条款。
- 点击“生成采购摘要”，说明无 Key 时使用规则摘要。

## 4:00-4:35 技术可信度

说明：

- 计算函数与 UI 解耦，有单元测试和端到端测试。
- AI 不修改评分，只生成文字分析。
- Excel 导出与页面使用同一份结果。
- 数据保存在浏览器，无数据库和隐私风险。

## 4:35-5:00 局限与下一步

“这个 Demo 不做真实爬虫、ERP 或审批流。真实落地下一步需要接入正式 RFQ 和数据库，并让技术、质量、财务共同签核。当前项目主要证明我能把复杂采购问题转成可解释、可复算、可展示的产品。”

## 现场故障预案

- 无网络：本地 `npm run dev`，无需 AI Key。
- 上传失败：使用页面已有种子数据继续演示。
- 时间缩短到 2 分钟：只演示“停机优先排名变化 + Busch 淘汰 + 决策包导出”。
