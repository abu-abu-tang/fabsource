# FabSource 新手教程

> 适用页面：FabSource 晶圆厂干式真空泵寻源比选工作台  
> 版本日期：2026-09-24  
> 适用对象：第一次接触半导体设备采购的新手用户

## 先记住一句话

FabSource 不是“卖泵”的网站，而是一张**设备采购比较表**。它要回答的问题是：

> 晶圆厂需要购买 6 台干式真空泵。四家供应商都能报价格，但谁更值得买？

它不会只看“谁报价最低”，而会同时看：

1. 技术条件是否合格；
2. 五年总共要花多少钱；
3. 交期和售后服务是否可靠；
4. 设备是否容易坏、维护是否省心；
5. 供应中断、备件不足等风险；
6. 决策依据是否有来源、能不能复算。

如果你只记五句话，请记：

- 这不是真实报价页面，报价是教学模拟数据。
- 红色“硬门槛未通过”不能被低价抵消。
- “五年 TCO”不是采购价，而是五年的全部拥有成本。
- 权重改变，排名可能改变，但事实数据不会改变。
- AI 只能写摘要，不能修改供应商排名。

## 1. 这个场景到底在买什么？

### 1.1 晶圆厂是什么？

晶圆厂可以理解成一座非常高级、非常干净的“芯片制造工厂”。

- **晶圆**：一片圆形的硅片，看起来像金属光盘，它是制作芯片的基础材料。
- **12 英寸晶圆厂**：使用直径约 300 毫米晶圆的生产线。
- **芯片**：在晶圆上制造出大量微小电路，再切割、封装后成为芯片。

晶圆生产时，如果空气、颗粒或水汽进入工艺腔体，就可能让整批产品报废，所以很多工序必须在真空环境中完成。

### 1.2 CVD 是什么？

CVD 全称是 Chemical Vapor Deposition，中文通常叫“化学气相沉积”。

可以把它想象成：

> 让特定气体进入一个密闭腔体，在晶圆表面发生化学反应，形成一层非常薄、非常均匀的薄膜。

这层薄膜可能是绝缘层、导电层或保护层。晶圆要经历很多次类似工序，最后才能形成复杂的芯片结构。

### 1.3 干式真空泵有什么用？

真空泵的任务是把 CVD 腔体里的气体抽走，让腔体保持低压力环境。

- **干式**：泵腔内部不靠传统润滑油密封，减少油污染风险。
- **真空**：不是“里面什么都没有”，而是压力远低于正常大气压。
- **Sub-fab**：晶圆厂主生产层下方的辅助设备层，真空泵、管路和厂务设备常放在这里。

为什么真空泵重要？因为：

- 抽气能力不足，工艺窗口会受限；
- 泵突然故障，相关设备可能停机；
- 有害或腐蚀性气体处理不好，会加速设备损坏；
- 维护或备件等待太久，会让生产损失持续扩大。

所以真空泵虽然不是芯片本身，却是维持芯片生产的重要设备。

## 2. 用“买车”理解采购决策

假设公司要买 6 辆工作车。你会怎么比较？

- A 店报价最低，但油耗高、保养贵；
- B 店贵一点，但故障少、售后快；
- C 店车价适中，但交车要等半年；
- D 店报价便宜，却没有安全认证。

只看“车价”显然不够。FabSource 使用同一套逻辑比较真空泵：

| 采购问题 | FabSource 对应内容 |
| --- | --- |
| 车辆能不能满足工作需求 | 技术规格与硬门槛 |
| 车价和购置费用 | 报价与采购价 |
| 油费、电费和保养费用 | 能耗、维护、备件、服务合同 |
| 故障和修车损失 | MTBF、故障率、停机损失 |
| 售后和配件是否方便 | 现场响应、服务网络、本地备件 |
| 总花多少钱 | 五年 TCO |
| 不同偏好下选谁 | 权重策略与多准则评分 |

## 3. 十个最重要名词，用大白话解释

### 3.1 TCO：五年总拥有成本

TCO 是 Total Cost of Ownership，意为“总拥有成本”。

它不是只看第一次付给供应商的采购价，而是把设备买回来后的所有重要成本相加：

```text
五年 TCO = 采购价 + 运费/关税 + 安装调试 + 能耗 + 维护备件
         + 服务合同 + 预期停机损失 - 残值
```

举例：

- 泵 A 买得便宜，但耗电多，五年电费更高；
- 泵 B 买得贵，但故障少，停机损失低；
- 泵 C 价格居中，但服务合同和备件很贵；
- 最后可能不是采购价最低的泵总成本最低。

### 3.2 硬门槛

硬门槛可以理解为“没有它就不用继续比较”。

例如招标要求泵必须支持某种接口。接口不匹配，哪怕价格再低，也无法直接安装。FabSource 对以下内容设置硬门槛：

- N₂ 抽速；
- 极限压力；
- 进气法兰；
- 额定功率；
- 腐蚀气体兼容；
- SEMI S2；
- CE；
- 安全联锁接口。

硬门槛只有“通过”与“不通过”，不会被其他高分抵掉。

### 3.3 加权评分

有些条件不是“必须满足”，而是“谁更好”。例如：

- 抽速越大越好；
- 功率越低越好；
- 交期越短越好；
- MTBF 越长越好；
- 服务响应越快越好。

FabSource 把这些表现转换成 0-100 分，再按权重合成总分。

权重意思是“这件事有多重要”。例如“成本优先”策略会把 TCO 权重提高到 50%，而“停机优先”策略更看重交付服务和可靠性。

### 3.4 报价归一

不同供应商的报价口径可能完全不同：

- 一个用美元，一个用欧元，一个用人民币；
- 一个含税，一个未税；
- 一个送到工厂，一个要自己去原厂提货；
- 一个包含安装，一个安装费另算。

“归一”就是先换算成同一种币种、税费和交付口径，再比较。否则就是把不同的东西硬放在一起比，很容易得出错误结论。

### 3.5 Incoterm 贸易条款

Incoterm 可以理解为“谁负责把货送到哪里、谁承担路上风险”。

| 术语 | 简单理解 |
| --- | --- |
| EXW | 买方到卖方工厂自提，买方承担后续运输 |
| FOB | 卖方把货送到装运港，之后的国际运输由买方安排 |
| CIF | 卖方支付到目的港的运费和保险，但关税等费用通常另算 |
| DDP | 卖方负责运到指定地点并完成进口清关，买方通常最省事 |

### 3.6 SEMI S2

SEMI S2 是半导体设备安全相关标准。对晶圆厂来说，它相当于设备进入产线前的“安全体检报告”。

缺少 SEMI S2 证据包，不代表泵一定不能用，而是意味着安全审查可能无法通过，风险不能被采购人员自行忽略。

### 3.7 MTBF

MTBF 是 Mean Time Between Failures，平均无故障时间。数值越高，通常表示设备平均能连续运行更久、故障间隔更长。

它不是“绝对不会坏”，只是用于比较可靠性。

### 3.8 交期与现场响应

- **交期**：从下单到收到设备大约要多久。
- **现场响应**：设备出问题后，服务人员多久能到现场。
- **备件交期**：需要更换零件时，零件多久能送到。
- **本地备件支持**：供应商是否在当地有常用备件库存。

对晶圆厂来说，设备晚到会影响产能，设备坏了响应慢会造成持续停机损失。

### 3.9 N₂ 吹扫

N₂ 是氮气。吹扫是把氮气送入泵内，用来稀释或带走腐蚀性、容易沉积的工艺气体和副产物。

吹扫流量不是越大越好，因为氮气也要成本；太小又可能保护不足，因此需要平衡。

### 3.10 残值

残值可以理解为设备用满五年后，仍然可能具有的剩余价值。

例如设备原价 100 万元，五年后还能卖 8 万元，那么计算总成本时可以扣掉这部分价值。残值越低，设备最终留下的经济价值越低。

## 4. 页面六个模块怎么读？

左侧导航有六个文字入口。第一次使用时，建议按下面顺序看。

### 4.1 项目总览

这是“结论页”，给人快速了解当前情况。

页面首先显示：

- 当前首选供应商；
- 首选的五年 TCO；
- 最低价格方案；
- 因硬门槛被淘汰的供应商数量。

下面的供应商排序不是随机排列，而是根据当前策略和权重自动计算。

排序中的标识：

| 标识 | 含义 |
| --- | --- |
| 参与推荐 | 通过硬门槛，可以参与最终排名 |
| 硬门槛未通过 | 有强制条件不满足，不进入推荐 |
| 数据待补充 | 报价或参数不完整，暂时不能可靠计算 |

“关键判断”告诉你当前最需要注意的事情。例如 Busch 虽然价格较低，但缺少 SEMI S2，所以不能仅凭低价进入推荐。

“评估假设”说明计算使用什么条件，例如五年、6 台、每年运行多少小时、停机一小时损失多少钱。改变这些假设，结果也会改变。

### 4.2 规格门槛

这一页回答：“哪些泵具备参与竞争的基础条件？”

页面包含：

- 规格项总数；
- 强制要求数量；
- 发现的硬门槛问题；
- 四家供应商的技术得分；
- 每一家在每个规格项上的表现。

表格里有两种要求：

- **硬性**：不通过就淘汰；
- **加权**：不淘汰，但会影响技术分。

阅读方法：

1. 先看是否有红色“硬门槛未通过”；
2. 再看目标值是否满足；
3. 最后比较通过者的技术得分。

不要只比较一个参数。抽速很高但能耗很大，或技术很好但交期很长，都不是完整结论。

### 4.3 报价归一

这一页回答：“大家的报价是不是在同一个口径上？”

系统会统一处理：

- 币种；
- 汇率快照；
- 税费；
- Incoterm；
- 运费；
- 关税；
- 安装调试；
- 年度维护；
- 首批备件；
- 服务合同；
- 残值；
- 交期、质保和现场响应。

如果没有归一，就会出现一种错误：

> 供应商 A 报的是未税出厂价，供应商 B 报的是含税到厂价，直接比数字没有意义。

页面同样支持导入 XLSX 或 CSV。导入不是必须操作；首次体验可以直接使用内置模拟数据。

### 4.4 决策分析与计算轨迹

这一页是整套工具的核心。

#### 决策策略

四套策略代表四种采购偏好：

| 策略 | 适合什么情况 |
| --- | --- |
| 综合平衡 | 没有特别偏好，常规评估 |
| 成本优先 | 预算压力大，技术方案已经确认 |
| 停机优先 | 设备是关键单点，停机损失非常高 |
| 本地化/韧性 | 更重视本地服务、备件和供应连续性 |

选择策略后，页面会立即重新计算排名。

#### 权重

五个维度的含义：

- **五年 TCO**：五年总成本，越低越好；
- **技术符合度**：规格匹配程度；
- **交付与服务**：交期、响应、服务网络；
- **质量与可靠性**：MTBF、维护间隔、故障率；
- **供应风险**：本地备件、稳定性、断供风险。

页面会展示归一化后的百分比。原始权重即使加起来不是 100%，系统也会按比例换算。

#### 场景假设

这里可以修改采购数量、评估周期、年运行小时、电价和停机损失。

这些数字不是装饰，它们直接进入 TCO。例如：

- 电价提高，功率低的泵会更有优势；
- 停机损失提高，故障率低、响应快的泵会更有优势；
- 评估年限增加，维护和电费差异会被放大。

#### 五年 TCO 构成图

柱状图把成本拆成：

- 采购价；
- 物流和安装；
- 能耗；
- 维护与服务；
- 停机损失。

柱子越矮，通常代表总成本越低，但还要结合硬门槛和权重一起看。

#### 五维评分雷达图

雷达图展示前两名在不同维度的相对强弱。

越靠近外圈，代表该维度得分越高。雷达图适合看“谁擅长什么”，不适合单独决定最终胜负。

#### 供应商评分卡

评分卡展示：

- 排名；
- 五年 TCO 得分；
- 技术得分；
- 交付服务得分；
- 质量可靠性得分；
- 供应风险得分；
- 综合得分。

点击某一个供应商后，右侧会显示这一家的“计算轨迹”，也就是钱和分数是怎样算出来的。

#### 计算轨迹

计算轨迹用文字展示关键公式，例如：

- 用什么汇率；
- 是否含税；
- 能耗如何计算；
- 停机损失如何计算；
- 五维分数如何合成总分。

它的作用是让面试官或采购负责人可以追问：

> 这个结论到底怎么来的？

#### 技术符合度热力图

热力图适合快速找短板：

- 绿色通常代表表现更好；
- 黄色代表需要关注；
- 红色代表不通过或明显偏弱。

#### 策略敏感性

这张折线图把同一个供应商放进四套策略中比较。

如果一家供应商在所有策略下都领先，说明优势比较稳定。  
如果排名在不同策略下变化明显，说明决策对“什么最重要”非常敏感。

### 4.5 推荐与谈判

这一页是“准备开会拍板”时看的。

页面给出：

- 首选供应商；
- 备选供应商；
- 首选与次选的 TCO 差异；
- 推荐理由；
- 谈判要点；
- 签约前风险问题；
- 可选 AI 摘要。

“推荐”不是一句简单的“买它”，而是包含：

- 为什么推荐；
- 还需要争取什么价格或条款；
- 哪些风险必须在签约前解决；
- 如果首选谈不下来，备选是谁。

### 4.6 来源与审计

这一页回答：“这些数字是从哪里来的？”

内容分为：

- 公开参数；
- 教学模拟报价；
- 场景假设；
- 系统计算结果。

真实项目中，每一项技术参数都应该能追溯到：

- 官方规格书；
- 正式 RFQ；
- 供应商澄清；
- 测试报告；
- 审核记录。

当前 Demo 的报价全部是模拟数据，不能拿去当真实采购依据。

## 5. 用当前示例完整走一遍

当前 Demo 的四家供应商如下。

| 供应商 | 型号 | 五年 TCO | 默认综合分 | 当前状态 |
| --- | --- | ---: | ---: | --- |
| 荏原制作所 | Ebara EV-SA20 | ¥4,026,690 | 85.0 | 默认第一 |
| 爱德华兹真空 | Edwards iXH1000 | ¥4,166,333 | 76.5 | 停机优先第一 |
| 普发真空 | Pfeiffer Vacuum ACP 630 | ¥4,362,857 | 49.0 | 参与比较 |
| 普旭真空 | Busch COBRA NS 0600 C | ¥4,629,774 | 33.6 | 硬门槛淘汰 |

### 5.1 先看谁被淘汰

Busch 没有满足 SEMI S2 要求，因此被标为“硬门槛未通过”。

它不能用更低的总分或折扣换成推荐资格。原因是：

- 晶圆厂设备需要安全审查；
- 缺少证据包会增加项目延期和整改风险；
- 采购人员不能单方面替代安全、质量和法务结论。

这一步说明：**硬门槛先于排名。**

### 5.2 再看谁的总成本最低

在有效供应商里：

- 荏原的五年 TCO 最低，约 402.7 万元；
- 爱德华兹约 416.6 万元；
- 普发约 436.3 万元。

荏原人民币含税、DDP 到厂，前期采购口径比较容易比较。  
爱德华兹虽然采购价更高，但能耗、服务响应和可靠性表现更好。

### 5.3 为什么默认首选是荏原？

默认“综合平衡”权重是：

- TCO 35%；
- 技术 25%；
- 交付服务 15%；
- 质量可靠性 15%；
- 供应风险 10%。

荏原的 TCO 得分最高，同时在技术和服务方面没有出现致命短板，所以综合分最高。

这不表示荏原在所有方面都最好。例如：

- 爱德华兹的交期、响应速度和可靠性更好；
- 荏原的主要优势是中位成本和比较完整的到厂报价。

### 5.4 为什么“停机优先”会换成爱德华兹？

选择“停机优先”后，权重变为：

- TCO 10%；
- 技术 20%；
- 交付服务 30%；
- 质量可靠性 30%；
- 供应风险 10%。

此时成本的重要性下降，交期、现场响应、MTBF 和故障率的重要性增加。

爱德华兹的优势包括：

- 交期 14 周，快于荏原的 18 周；
- 现场响应 24 小时，快于荏原的 36 小时；
- MTBF 更高；
- 故障率更低；
- 质量可靠性得分更高。

因此，虽然爱德华兹的五年 TCO 比荏原高约 14 万元，但在高停机损失场景下更值得考虑。

### 5.5 为什么普发排名较后？

普发的技术表现不错，但：

- 五年 TCO 最高；
- 交期较长；
- 质保年限较短；
- 可靠性、故障率和服务表现弱于前两名。

这说明“技术合格”不等于“采购上一定最优”。采购决策是技术、成本、交付和风险的组合。

### 5.6 这家页面最重要的演示动作

如果你需要给别人演示，请按下面顺序：

1. 打开“项目总览”，说明当前首选和 Busch 被淘汰；
2. 打开“规格门槛”，说明 SEMI S2 为什么是硬门槛；
3. 打开“报价归一”，说明为什么不能直接比较美元、欧元和人民币；
4. 打开“决策分析”，选择“成本优先”，观察荏原第一；
5. 切换到“停机优先”，观察爱德华兹第一；
6. 点击爱德华兹或荏原，查看计算轨迹；
7. 打开“推荐与谈判”，阅读风险追问和谈判建议；
8. 打开“来源与审计”，说明模拟数据和公开参数的边界。

这个流程可以在 5-8 分钟内讲清楚。

## 6. 第一次访问的推荐阅读顺序

### 路线 A：只想快速看懂，约 3 分钟

## 7. 常见问题

### 7.1 我完全不懂半导体，能用吗？

可以。使用该项目不需要会设计真空泵，只需要理解：

- 硬门槛代表不能违反的底线；
- TCO 代表长期总成本；
- 权重代表采购部门当前更重视什么；
- 排名只是决策辅助，不是最终合同。

### 7.2 为什么不是最低价直接中标？

因为最低采购价可能对应：

- 更高的电费；
- 更长的交期；
- 更贵的维护和备件；
- 更高的故障率和停机损失；
- 本地服务不足；
- 缺少安全认证。

FabSource 的目的正是防止“只看采购价”的错误。

### 7.3 页面里的报价是真的吗？

不是。当前报价、故障率、停机损失和服务费用都是教学模拟数据。

品牌、产品族和部分公开参数来自官方产品资料，但采购前仍需核对正式规格书和 RFQ。

### 7.4 为什么同一个供应商有时第一，有时不是第一？

因为权重改变了。

- 成本优先更看重 TCO；
- 停机优先更看重交付服务和可靠性；
- 本地化/韧性更看重服务和供应风险。

事实没有变化，变化的是“什么更重要”。

### 7.5 分数越高就越适合我吗？

不一定。分数是当前权重和当前假设下的结果。

如果实际情况变化，例如：

- 电价上涨；
- 设备冗余增加；
- 停机损失下降；
- 交货地点变化；
- 汇率变化；

排名也可能改变。

### 7.6 硬门槛未通过为什么还显示分数？

页面会计算一个参考分，方便你了解它与其他供应商的差距。

但是硬门槛未通过时，供应商不会获得排名，也不会进入最终推荐。显示分数不等于恢复资格。

### 7.7 为什么 TCO 得分有 0 分？

TCO 采用相对评分。在参与排名的供应商中：

- 五年成本最低者通常为 100 分；
- 五年成本最高者通常为 0 分。

0 分不代表设备免费或毫无价值，只代表在本次比较中相对成本最高。

### 7.8 为什么 AI 不能直接决定供应商？

因为采购结论需要：

- 可追溯；
- 可复算；
- 能解释；
- 可审计；
- 能承担责任。

AI 适合写摘要和风险问题，但不应在没有人审核的情况下改变量化排名。

### 7.9 我能导入自己的报价吗？

可以。报价页支持 XLSX 和 CSV 导入，也提供模板。

导入时系统会检查：

- 供应商编号是否存在；
- 单价和汇率是否有效；
- 税费和贸易条款是否完整；
- 交期、质保和服务字段是否缺失。

导入数据只保存在当前浏览器，不会写入服务端数据库。

### 7.10 为什么不同供应商的指标单位那么多？

因为设备采购本身就是跨专业决策：

- 工艺工程师关心抽速、压力、气体兼容；
- 厂务工程师关心功率、噪声、占地和接口；
- 采购关心报价、税费、交期和合同；
- 质量与安全关心认证、MTBF 和风险；
- 财务关心五年总成本。

FabSource 把这些信息放在一个页面里，但不能替代各部门的正式审核。

## 9. 最后总结

把 FabSource 当成一张“有证据、有公式、能调整偏好的采购比较表”：

1. **硬门槛**决定谁能进入比赛；
2. **报价归一**决定数字能不能公平比较；
3. **五年 TCO**决定长期成本高低；
4. **权重策略**决定不同业务偏好下谁更合适；
5. **计算轨迹**决定结论能不能被追问；
6. **推荐与谈判**把分析结果转成下一步行动；
7. **来源与审计**告诉你哪些是事实，哪些是模拟假设。

普通人不需要先看懂所有半导体术语。先理解“先过门槛、再算总成本、最后按偏好比较”，就已经能读懂 80% 的页面。
